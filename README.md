# ReqRipple

## Overview

ReqRipple is a full‑stack application for managing software requirements, traceability graphs, change requests and impact analysis.

- **Backend**: FastAPI (`backend/`) with SQLAlchemy, Pydantic models and a SQLite database.
- **Frontend**: React + TypeScript (`frontend/`) built with Vite, Tailwind CSS and Zustand for state management.
- **Tests**: Pytest for the backend (`backend/tests/`) and the full build pipeline.

## Quick Start

### Prerequisites
- Python 3.10+ (recommended to use `pyenv` or a virtualenv)
- Node.js 20+ and npm
- `git`

### Backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# Run migrations (creates `reqripple.db`)
alembic upgrade head
# Start the API
uvicorn app.main:app --reload
```
The API will be available at `http://127.0.0.1:8000`.

### Frontend
```bash
cd frontend
npm install   # install dependencies
npm run dev    # start Vite dev server (proxy → backend)
```
Open `http://localhost:5173` in a browser.

### Build for Production
```bash
cd frontend
npm run build   # outputs static files to `frontend/dist`
```
You can serve the `dist` folder with any static file server (e.g., `python -m http.server` or Nginx).

## Running Tests
```bash
cd backend
source .venv/bin/activate
pytest -v   # all 17 tests should pass
```

## Development Scripts
A convenient `Makefile` is provided (see `Makefile`). You can run:
- `make backend` – start the backend server.
- `make frontend` – start the Vite dev server.
- `make test` – run backend tests.
- `make build` – build the frontend assets.

## CI/CD
A GitHub Actions workflow (`.github/workflows/ci.yml`) runs the test suite and the frontend build on every push.
